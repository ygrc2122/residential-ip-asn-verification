## 先搞清楚你买的是哪种“静态”

市面上叫“静态住宅”的产品分三类，混淆是退货和封号的主要来源。

**第一类，静态住宅（真家宽 / ISP 代理）。** ASN 归属民用宽带运营商，IP 长期固定，扩容要靠真实装机，所以最贵。养号、店铺长期登录选这一类。

**第二类，长效静态。** IP 确实固定，速度也快，但 ASN 归属是数据中心或城域网出口。它的“静态”是真的，“住宅”是缺的。很多平台把这类直接标成静态住宅，实际检测会被判为 hosting。商家未必在骗人，只是口径不同，但你需要知道自己买的是哪一类。

**第三类，“静态”指会话保持（Sticky Session）。** 底层仍是动态池，粘住一段时间后照样换。拿来做采集够用，拿来养号会出问题：账号登录到第三周突然换了城市，风控立刻标记。

下单前问三个问题基本能问清：

1. 这条 IP 的 ASN 是 ISP 还是 IDC？
2. 租期内 IP 会不会变，变了算不算违约？
3. 是独享还是共享，同一时间段这条 IP 上还有没有别的用户？

## 四步验真：ASN 先筛，再用实际用途复核

### 第 1 步，查 ASN

打开 ipinfo.io/<你的IP> 或 bgp.he.net，看 ASN 的 owner。AT&T、Comcast、Verizon、中国电信、中国联通、中国移动属于真住宅出身；Amazon、Google Cloud、DigitalOcean、阿里云、腾讯云、Vultr 属于机房；名字里带 IDC、Hosting、Data Center 的直接排除。小型区域 ISP 但 IP 段标注 hosting 的，进入第 2 步复核。

这一步能筛掉市面上相当一部分“静态住宅”。

### 第 2 步，查三个第三方类型库

ipapi.is 或 ip-api.com 看 type 字段（residential / hosting / proxy），IP2Location 看 usage type（ISP / DCH / SES），Scamalytics 看 fraud score。判定标准是至少两个库标为 residential 或 ISP，且 fraud score 低于 25。

这里有个需要注意的分歧。一种观点认为 ASN 归属可以一票否决，因为 IP 资源稀缺性决定价格，商家没有动机在这上面做手脚；另一种观点认为，大型运营商同时经营数据中心业务，云厂商也会租用运营商网段，光看登记信息会被“登记像住宅、用途是机房”的托管服务器骗过去，必须按具体地址的实际用途判定。

两种说法可以合起来用：ASN 先做粗筛，类型库做交叉复核，两个库以上一致才往下走。分歧本身也是信息，说明这个 IP 的判定不稳。

WePC 这两款就是现成例子。第三方对韩国世宗档的检测结果是：IPinfo 和 ipregistry 判为住宅宽带，AbuseIPDB 记为低风险，ipapi 判为其他类型，IP2Location 判为机房。英国档更一致一些，IPinfo、ipregistry、ipapi 三家都判住宅，AbuseIPDB 低风险，同样只有 IP2Location 判机房。

两个案例里 IP2Location 都站在对立面。这不代表另外四家一定对，但足以说明单一数据库的结论不能当定论用，尤其是你打算拿这条 IP 去开长期账号的时候。

### 第 3 步，查黑名单与滥用记录

AbuseIPDB 看举报次数和最近举报时间，Spamhaus ZEN、SpamCop 等主流 DNSBL 看是否命中。判定标准是近 90 天无举报、黑名单零命中。

IP 出身真不等于 IP 干净。一条真家宽 IP，上一个用户拿它刷过单，你接手就是个脏 IP。下单前问一句能不能指定“未被使用过的新 IP”，比看十张演示截图有用。

### 第 4 步，查 DNS / WebRTC 泄漏与时区一致性

打开 browserleaks.com/webrtc 和 ipleak.net，看是否泄漏真实出口 IP、DNS 解析走本地还是代理端、时区和语言是否与 IP 地区一致。风控看的是整组信号是否自洽，不是单看 IP。

四步全过，可以用于养号；缺一条，只适合采集。

## 三个坑和两个配置错误

**坑一，“独享”被偷换成“独享线路”。** 独享 IP 指这条 IP 只给你用；独享线路只说明带宽不与人分享，IP 可能仍在共享段上。共享段上有人违规，你的账号跟着受连带。

**坑二，流量单向还是双向计费。** 标称 2000GB，双向计费时上传也扣额度，实际可用可能只剩一半。做多开、挂直播、跑云手机的上传量往往比下载大。WePC 两款标的都是 2TB 双向流量，按双向理解预算就行。

**坑三，预订制加等待期不退款。** 静态住宅 IP 是物理稀缺资源，付款后排队交付，等待期内通常不退，到期时间从实际开通日起算而不是付款日。下单前问清这一条。

配置层最致命的两个错误：一是只改 IP 不改时区和语言，IP 在洛杉矶、系统时区 UTC+8、浏览器语言 zh-CN，三者对不上已经很可疑；二是 WebRTC 泄漏真实出口，需要在客户端屏蔽 3478 和 19302 端口。另外，一条 IP 同时登多个账号本身就违反隔离原则，设备指纹、Cookie、行为节奏同样参与关联判定。

## 常见问题

**一个静态 IP 能挂几个账号？**
没有通用数字。安全做法是一账号一独立 IP，同 C 段也不要扎堆。IP 只是隔离的一层，设备指纹和行为节奏同样参与判定。

**IP 被封了怎么办？**
任何平台都不保证 IP 永久可用。能换 IP 的服务商通常只对“连不上”的 IP 负责，因业务原因被目标服务限制的一般不给换。下单前把这条写进确认清单。

**SOCKS5 和 L2TP 怎么选？**
SOCKS5 是应用层代理，单应用生效，支持 UDP，适合浏览器和客户端分流。L2TP 是隧道协议，设备级生效，适合路由器、电视盒子、游戏主机。

**付款后多久开通？**
现货档通常即时到数小时，预订档可能数天到两周。到期时间从实际开通日起算，付款日不算。

**静态是不是永不封？**
不是。“静态”只指地址不变，不指账号安全。IP 只是风控的一个维度。

**能支付宝付款吗？**
WePC 两款都支持支付宝和 PayPal，账户币种可选澳元或人民币，实际扣款以结算页显示为准。
